# UCI Iris Dataset

- Source: [UCI Machine Learning Repository — Iris](https://archive.ics.uci.edu/dataset/53/iris)
- Citation: Fisher, R. (1936). Iris [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C56C76.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).
- Downloaded from UCI's official dataset archive: `https://archive.ics.uci.edu/static/public/53/iris.zip`.

`iris.data` is a headerless CSV with 150 records and five columns, in this order:

1. Sepal length (cm), numeric feature
2. Sepal width (cm), numeric feature
3. Petal length (cm), numeric feature
4. Petal width (cm), numeric feature
5. Iris species, target label

The downloaded file has 50 records for each of `Iris-setosa`,
`Iris-versicolor`, and `Iris-virginica`. The four measurements and target label
have no missing values. `iris.names` contains the source's dataset notes.
