# Iris Flower Classification

## Project Overview

This project focuses on developing a Machine Learning classification model to identify Iris flower species based on their physical measurements.

## Dataset

Iris Flower Classification Dataset – UCI Machine Learning Repository.

Dataset: https://archive.ics.uci.edu/dataset/53/iris

## Classes
- Iris Setosa
- Iris Versicolor
- Iris Virginica

## Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
